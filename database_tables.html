Mở file báo cáo DATN.docx của bạn, di chuyển con trỏ chuột đến mục 2.8 Cơ sở dữ liệu và nhấn Ctrl + V. 2.8.1 Bảng users (Tài khoản người dùng)

Bảng này lưu trữ thông tin tài khoản người dùng, phân quyền truy cập giữa quản trị viên (Admin) và khách mua hàng (Customer), đồng thời hỗ trợ liên kết đăng nhập qua bên thứ ba (Google).

Tên cột Kiểu dữ liệu Khóa / Thuộc tính Mô tả chi tiết
id BigInt Primary Key, Auto Increment Khóa chính tự tăng của người dùng
name String(255) Not Null Họ và tên hiển thị của người dùng
username String(255) Unique, Not Null Tên tài khoản dùng để đăng nhập
email String(255) Unique, Not Null Địa chỉ email của người dùng
password String(255) Not Null Mật khẩu tài khoản (đã mã hóa hash)
phone String(255) Nullable Số điện thoại liên hệ
address Text Nullable Địa chỉ giao hàng mặc định
avatar String(255) Nullable Đường dẫn ảnh đại diện hoặc URL ảnh Google
google_id String(255) Nullable Mã định danh khi đăng nhập bằng Google OAuth
role String(255) Default: 'customer' Vai trò tài khoản ('admin' hoặc 'customer')
is_active Boolean Default: true Trạng thái hoạt động (1: Hoạt động, 0: Khóa)
remember_token String(100) Nullable Mã token duy trì đăng nhập của Laravel
created_at Timestamp Nullable Thời điểm tạo tài khoản
updated_at Timestamp Nullable Thời điểm cập nhật tài khoản gần nhất

2.8.2 Bảng otps (Mã xác thực một lần)

Lưu trữ các mã OTP dùng để xác thực kích hoạt tài khoản hoặc xác nhận yêu cầu đặt lại mật khẩu của người dùng.

Tên cột Kiểu dữ liệu Khóa / Thuộc tính Mô tả chi tiết
id BigInt Primary Key, Auto Increment Khóa chính tự tăng
email String(255) Not Null Địa chỉ email nhận mã OTP
otp String(255) Not Null Mã xác thực gồm 6 chữ số
type String(255) Not Null Loại OTP ('register', 'reset_password'...)
expires_at Timestamp Not Null Thời gian mã OTP hết hạn sử dụng
is_used Boolean Default: false Đánh dấu mã đã sử dụng chưa (1: Rồi, 0: Chưa)
created_at Timestamp Nullable Thời gian khởi tạo mã
updated_at Timestamp Nullable Thời gian cập nhật gần nhất

2.8.3 Bảng categories (Danh mục đồng hồ)

Quản lý các danh mục phân loại đồng hồ (ví dụ: Đồng hồ nam, Đồng hồ nữ) hỗ trợ cấu trúc phân cấp đa cấp thông qua thuộc tính đệ quy parent_id.

Tên cột Kiểu dữ liệu Khóa / Thuộc tính Mô tả chi tiết
id BigInt Primary Key, Auto Increment Khóa chính tự tăng
name String(255) Not Null Tên của danh mục sản phẩm
slug String(255) Unique, Not Null Đường dẫn URL thân thiện
parent_id BigInt Foreign Key (categories.id), Nullable Liên kết đệ quy tới danh mục cha
image String(255) Nullable Ảnh đại diện của danh mục
description Text Nullable Mô tả ngắn gọn về danh mục
is_active Boolean Default: true Trạng thái hiển thị (1: Hiển thị, 0: Ẩn)
sort_order Integer Default: 0 Thứ tự sắp xếp hiển thị của danh mục
created_at Timestamp Nullable Thời điểm khởi tạo
updated_at Timestamp Nullable Thời điểm cập nhật gần nhất

Lưu giữ thông tin về các nhà sản xuất/thương hiệu đồng hồ nổi tiếng được trưng bày trên hệ thống (Casio, Seiko, Citizen...).

name String(255) Not Null Tên hãng đồng hồ
slug String(255) Unique, Not Null Đường dẫn URL thân thiện của thương hiệu
logo String(255) Nullable Đường dẫn lưu hình ảnh logo của thương hiệu
description Text Nullable Giới thiệu lịch sử, xuất xứ của hãng
is_active Boolean Default: true Trạng thái kích hoạt (1: Có, 0: Không)
created_at Timestamp Nullable Thời điểm khởi tạo
updated_at Timestamp Nullable Thời điểm cập nhật gần nhất

2.8.5 Bảng products (Thông tin sản phẩm đồng hồ)

Bảng nghiệp vụ quan trọng nhất lưu trữ đầy đủ thông số kỹ thuật chi tiết của đồng hồ, giá cả, số lượng tồn kho, cache đánh giá và phần mô tả được tạo tự động bởi trí tuệ nhân tạo.

Tên cột Kiểu dữ liệu Khóa / Thuộc tính Mô tả chi tiết
id BigInt Primary Key, Auto Increment Khóa chính tự tăng của sản phẩm
name String(255) Not Null Tên sản phẩm đồng hồ
slug String(255) Unique, Not Null Đường dẫn URL thân thiện sản phẩm
category_id BigInt Foreign Key (categories.id), Cascade Sản phẩm thuộc về danh mục nào
brand_id BigInt Foreign Key (brands.id), Cascade Sản phẩm thuộc về thương hiệu nào
description Text Nullable Đoạn mô tả chi tiết sản phẩm thủ công
price Decimal(12,0) Not Null Giá gốc niêm yết của đồng hồ (VNĐ)
sale_price Decimal(12,0) Nullable Giá khuyến mãi đặc biệt (VNĐ)
stock Integer Default: 0 Số lượng hàng hiện tại còn trong kho
thumbnail String(255) Nullable Ảnh đại diện chính hiển thị ngoài danh sách
sku String(255) Unique, Nullable Mã quản lý tồn kho hàng hóa (SKU)
material String(255) Nullable Chất liệu vỏ đồng hồ (Thép không gỉ...)
glass_material String(255) Nullable Chất liệu kính mặt số (Kính Sapphire, Hardlex...)
band_material String(255) Nullable Chất liệu dây đeo (Dây da, Dây thép...)
water_resistance String(255) Nullable Mức độ chống nước (3 ATM, 5 ATM...)
movement String(255) Nullable Bộ máy truyền động của đồng hồ (Quartz, Automatic...)
case_size String(255) Nullable Đường kính mặt số đồng hồ (38mm, 40mm...)
color String(255) Nullable Màu sắc chủ đạo của đồng hồ
is_active Boolean Default: true Trạng thái bày bán (1: Bán, 0: Ẩn)
is_featured Boolean Default: false Đưa sản phẩm lên nhóm nổi bật ở trang chủ
view_count Integer Default: 0 Tổng lượt truy cập xem sản phẩm
ai_description Text Nullable Bài viết mô tả tiếp thị lôi cuốn do AI Gemini tạo
rating_avg Decimal(3,2) Default: 0 Cache điểm đánh giá trung bình từ 1.0 đến 5.0
rating_count Integer Default: 0 Cache tổng số lượt đánh giá
created_at Timestamp Nullable Thời điểm nhập sản phẩm lên web
updated_at Timestamp Nullable Thời điểm cập nhật gần nhất

2.8.7 Bảng orders (Đơn hàng mua sắm)

Bảng quản lý thông tin mua hàng, địa chỉ giao nhận của khách, các phương thức thanh toán trực tuyến và trạng thái vận đơn.

Tên cột Kiểu dữ liệu Khóa / Thuộc tính Mô tả chi tiết
id BigInt Primary Key, Auto Increment Khóa chính tự tăng của đơn hàng
order_code String(255) Unique, Not Null Mã đơn hàng định dạng chuẩn (Ví dụ: DH20260521)
user_id BigInt Foreign Key (users.id), Cascade Tài khoản thực hiện mua hàng
coupon_id BigInt Foreign Key (coupons.id), Set Null Mã giảm giá áp dụng cho đơn (nếu có)
receiver_name String(255) Not Null Họ tên của người nhận hàng thực tế
receiver_phone String(255) Not Null Số điện thoại của người nhận hàng
receiver_address Text Not Null Địa chỉ chi tiết nhận hàng
subtotal Decimal(12,0) Not Null Tổng giá trị đơn hàng trước khi giảm giá (VNĐ)
discount Decimal(12,0) Default: 0 Số tiền được chiết khấu giảm giá (VNĐ)
total Decimal(12,0) Not Null Số tiền cuối cùng khách phải trả (VNĐ)
payment_method Enum 'cod', 'vnpay' Phương thức: Thanh toán khi nhận hàng hoặc VNPay
payment_status Enum 'pending', 'paid', 'failed' Trạng thái thanh toán hiện tại của đơn hàng
vnpay_transaction_id String(255) Nullable Mã giao dịch trả về từ cổng VNPay
status Enum 'pending', 'confirmed', 'shipping', 'delivered', 'cancelled' Trạng thái xử lý vận chuyển của đơn hàng
note Text Nullable Lời nhắn dặn dò của khách hàng khi đặt
qr_code Text Nullable Mã QR chứa thông tin thanh toán chuyển khoản nhanh
created_at Timestamp Nullable Thời điểm khách đặt mua
updated_at Timestamp Nullable Thời điểm cập nhật thông tin đơn hàng

2.8.10 Bảng reviews (Đánh giá & AI Phân tích Cảm xúc)

Lưu lại đánh giá xếp hạng sao và nhận xét của khách hàng về sản phẩm sau khi đã mua. Đặc biệt, bảng này tích hợp các trường thông minh phục vụ cho mô-đun AI xử lý phân tích cảm xúc phản hồi.

Tên cột Kiểu dữ liệu Khóa / Thuộc tính Mô tả chi tiết
id BigInt Primary Key, Auto Increment Khóa chính tự tăng

product_id BigInt Foreign Key (products.id), Cascade Sản phẩm được đánh giá
order_id BigInt Foreign Key (orders.id), Set Null Đơn hàng mua sản phẩm để xác nhận đánh giá thực
rating TinyInt Not Null Số sao đánh giá của khách hàng (1 đến 5 sao)
comment Text Nullable Nhận xét viết bằng văn bản của khách hàng

sentiment Enum 'positive', 'neutral', 'negative', Nullable Trạng thái cảm xúc tự nhận diện bởi AI (Tích cực, Trung lập, Tiêu cực)
sentiment_score Decimal(4,2) Nullable Điểm cảm xúc cụ thể (0.00: Rất tệ -> 1.00: Cực thích)

2.8.16 Bảng ai_logs (Nhật ký hội thoại và giao dịch AI)

Bảng kỹ thuật cực kỳ quan trọng ghi chép chi tiết toàn bộ các lần tương tác giữa hệ thống của bạn với Google Gemini API (bao gồm input, output, tokens tiêu hao) để phục vụ cho phân tích kỹ thuật và giám sát tài nguyên.

Tên cột Kiểu dữ liệu Khóa / Thuộc tính Mô tả chi tiết
id BigInt Primary Key, Auto Increment Khóa chính tự tăng
user_id BigInt Foreign Key (users.id), Nullable ID người dùng thực hiện kích hoạt dịch vụ AI
type String(255) Not Null Phân loại dịch vụ ('chatbot', 'image_recognition', 'sentiment'...)
input LongText Not Null Dữ liệu/Lệnh văn bản gửi lên AI Gemini
output LongText Not Null Văn bản phản hồi chính thức nhận được từ AI Gemini
